# Student Grade Analyzer

A simple, beginner-friendly Python program that calculates student grades and class statistics.

## Requirements

- Python 3

No external libraries are needed.

## Run the application

From this folder, run:

```bash
python3 grade_analyzer.py
```

The program starts with three sample students so it can be tested immediately. To add more students, enter a name and a score from 0 to 100. Press Enter at the name prompt without entering a name to finish.

The program displays each student's score and letter grade, a grade distribution showing the number of students who received each grade from A to F, the class average, and the students with the highest and lowest scores.

Grades use this scale:

| Score | Grade |
| --- | --- |
| 80-100 | A |
| 70-79 | B |
| 60-69 | C |
| 50-59 | D |
| Below 50 | F |
